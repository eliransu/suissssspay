# SUISA.COACH - AI Enablement Coaching

Landing page for **Eliran Suisa** AI enablement coaching.

Focus: AI enablement, zero to hero, adoption, native AI companies.

**Flow:** show package quotes → schedule on Google Calendar → payment arranged after the call.

Calendar: https://calendar.app.google/ph5b4TAgbNsSec7j8

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Local fonts: Cormorant Garamond, satoshi, JetBrains Mono

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000/payment

## Notes

- No online payment on the page (quotes only)
- Primary CTA: Schedule with Eliran
